# iClaustron

A client library for RonDB 26.10 data nodes (an API node speaking the
NDB protocol) written in C-like Rust, MIT licensed, usable from Rust, C,
C++ and any language that can call C.

Status: release 1.0.0, on branch `1.0.0`, which takes the fixes to
the release; development goes on in `trunk`. It needs data nodes of
RonDB 26.10.0 or later. What each release brought is in
[`CHANGELOG.md`](CHANGELOG.md), and how one is made in
[`doc/releasing.md`](doc/releasing.md).

Rows are read and written by primary key and unique key, in
transactions, synchronously or asynchronously with callbacks, every row
size RonDB allows, with node failures handled; threads without a
connection of their own run their transactions through executors,
which send many threads' calls together. Tables and ordered indexes
are scanned, on a connection or through an executor, and the rows a
locking scan read can be updated or deleted through it; conditions and
updates run on the data nodes, and AUTO_INCREMENT values are handed
out.

- **Using it**: the user guide, [`doc/user-guide.md`](doc/user-guide.md),
  and the same twelve example programs in Rust and C in
  [`examples/`](examples/README.md).
- **The C API**: `include/iclaustron/ic_apid.h`, generated from
  `crates/ic_capi`; `cargo xtask install` installs `libiclaustron` with
  a pkg-config file.
- **The design and the plan**: [`doc/rust/`](doc/rust/README.md); start
  with the index there.

## Layout

```
crates/            the library, one crate per module (see doc/rust/03-module-map.md)
include/           the C header, generated by cbindgen from crates/ic_capi
examples/          the same programs in Rust and in C
tools/             command-line tools: describe a table, read, write, benchmark
xtask/             developer commands: cargo xtask check | style | header | install | test-integration | fuzz | tags | names
doc/user-guide.md  how to use the library
doc/rust/          the design and the plan
doc/dev-cluster.md how to run a RonDB 26.10 cluster for development
doc/releasing.md   how a release is checked, built, tagged and published
CHANGELOG.md       what each release brought
```

## Building

Requires a stable Rust toolchain (`rustup`, see `doc/rust/08-testing-and-tooling.md`).

```
cargo build --workspace
cargo test --workspace
cargo xtask check
```

The C library, built in release mode and installed with its header
and a pkg-config file:

```
cargo xtask install /usr/local        # or any prefix
```
